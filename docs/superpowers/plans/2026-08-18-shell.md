**Goal:** Build the scaffold every M3 screen plugs into — the theme, the five-tab shell, the HUD, the popup plumbing and Settings — with the five tab bodies left as placeholders.

**Architecture:** The kit colour arithmetic stays Flutter-free and hex-based in `lib/util/`; `lib/ui/theme/` is the only place a hex becomes a `Color`. The shell is an `IndexedStack` with `TickerMode` per child, enter-only slide transitions, routes for Settings and Event, and modal sheets for the three overlay screens. A `ShellController` owns navigation; the popup queue is pure logic under `lib/util/`.

**Tech Stack:** Flutter 3.38.3 / Dart 3.10.1, `flutter_riverpod`, `flutter_localizations`, node 26 for fixtures.

**Spec:** `docs/superpowers/specs/2026-08-18-shell-design.md`

## Global Constraints

- Source of truth is `../merge-empire-fc/src/`. Read a JS file in full before porting it.
- `lib/engine/`, `lib/data/`, `lib/i18n/`, `lib/state/`, `lib/util/` must never import `package:flutter/*` — enforced by `test/architecture_test.dart`. **The popup queue lands in `lib/util/` and is bound by this.**
- **Every user-facing string goes through `t()`.** Never a literal. The key must exist in `en` or `test/i18n/call_sites_test.dart` fails the build.
- Read values through a derived provider (`savePick` in `providers/game_providers.dart`), never the save map — the save is one mutable instance, so `==` never fires.
- Write through `game.update(...)`. A raw write needs a `notifyChanged()`.
- A takeover screen sets `tickGatesProvider` while it is up and clears it on the way out.
- Tab order is exactly `grid, squad, league, club, shop`. `league` is the raised centre tab and is icon-only.
- Comments: one short line each, never a block. This is a repo rule.
- Commit after every task.

//
// applyKitColor writes CSS custom properties onto <html> and <body> rather than
// returning anything, so the DOM it touches is stubbed and the writes recorded.
// Three surfaces are all it uses: documentElement.style, body.style, and
// body.classList, plus a body.background setter.
//
//   node tool/dump_kit_theme_reference.mjs > test/fixtures/kit_theme_reference.json

const makeStyle = (sink) => ({
  setProperty: (k, v) => { sink[k] = v; },
  set background(v) { sink['background'] = v; },
  get background() { return sink['background']; },
  set backgroundAttachment(v) { sink['background-attachment'] = v; },
  get backgroundAttachment() { return sink['background-attachment']; },
});

let light = false;
const rootVars = {};
const bodyVars = {};

globalThis.document = {
  documentElement: { style: makeStyle(rootVars) },
  body: {
    style: makeStyle(bodyVars),
    classList: { contains: (c) => c === 'light-mode' && light },
  },
};

const { applyKitColor } = await import('../../merge-empire-fc/src/utils/kitTheme.js');

const KITS = [
  'turf', 'humbug', 'sunset', 'midnight', 'empire', 'void',
  '#4caf50', '#ffd700', '#00c8ff', '#e53935', '#1a237e', '#ffffff', '#000000',
];

const out = { dark: {}, light: {} };
for (const mode of ['dark', 'light']) {
  light = mode === 'light';
  for (const kit of KITS) {
    for (const k of Object.keys(rootVars)) delete rootVars[k];
    for (const k of Object.keys(bodyVars)) delete bodyVars[k];
    applyKitColor(kit);
    out[mode][kit] = { ...bodyVars };
  }
}

process.stdout.write(JSON.stringify(out, null, 2));

They disagree. ```dart
/// One kit's derived surfaces, as hex strings. Turning these into `Color`s is
/// `lib/ui/theme/`'s job and nowhere else's.
class KitSurfaces {
  const KitSurfaces({
    required this.bg,
    required this.surface,
    required this.surface2,
    required this.border,
    required this.textMuted,
    required this.accent,
    required this.accentBright,
    required this.accentBrightInk,
    required this.accentInk,
    required this.hueRotate,
  });

  final String bg;
  final String surface;
  final String surface2;
  final String border;
  final String textMuted;
  final String accent;
  final String accentBright;
  final String accentBrightInk;
  final String accentInk;

  /// Degrees the kit art is rotated by.
  final int hueRotate;
}

/// The palette for a kit id — one of the six pattern names, or a `#rrggbb`.
///
/// Anything unrecognised lands on the default green rather than throwing: the
/// id comes off the save, so a future build's kit must not brick an older one.
KitSurfaces buildKitSurfaces({required String kitId, required bool light}) {
  final pattern = light ? _patternLight[kitId] : _patternDark[kitId];
  if (pattern != null) return pattern;
  final hex = kitId.startsWith('#') ? kitId : defaultKitColor;
  return light ? _lightHex(hex) : _darkHex(hex);
}
```

The six pattern kits are fixed tables in the JS — each branch of `applyKitColor`
writes literals rather than deriving anything — so they become two `const Map`s.
Transcribe all twelve entries from the source and let the fixture check the
typing: a wrong hex here is a silent colour change no other test would notice.

Create `lib/ui/theme/stripe_painter.dart`. Two of the six kits (`turf`, `humbug`) are `repeating-linear-gradient` stripes rather than a smooth gradient.

```dart
/// The two striped kits' background. The other four are smooth gradients, which
/// need no painter.
library;

import 'package:flutter/material.dart';

/// Vertical bands, dark first, repeating every `dark.width + light.width`.
class StripeDecoration extends Decoration {
  const StripeDecoration({
    required this.dark,
    required this.light,
    required this.darkWidth,
    required this.lightWidth,
  });

  final Color dark;
  final Color light;
  final double darkWidth;
  final double lightWidth;

  @override
  BoxPainter createBoxPainter([VoidCallback? onChanged]) =>
      _StripePainter(this);
}

class _StripePainter extends BoxPainter {
  _StripePainter(this.decoration);

  final StripeDecoration decoration;

  @override
  void paint(Canvas canvas, Offset offset, ImageConfiguration cfg) {
    final size = cfg.size ?? Size.zero;
    final period = decoration.darkWidth + decoration.lightWidth;
    if (period <= 0) return;
    final paintDark = Paint()..color = decoration.dark;
    final paintLight = Paint()..color = decoration.light;
    for (var x = 0.0; x < size.width; x += period) {
      canvas.drawRect(
        Rect.fromLTWH(offset.dx + x, offset.dy, decoration.darkWidth, size.height),
        paintDark,
      );
      canvas.drawRect(
        Rect.fromLTWH(
          offset.dx + x + decoration.darkWidth,
          offset.dy,
          decoration.lightWidth,
          size.height,
        ),
        paintLight,
      );
    }
  }
}
```

Stripe widths come from the JS: turf is 24px/24px, humbug 28px/28px. Read `TURF_BACKGROUND` and `HUMBUG_BACKGROUND` in `utils/kitTheme.js` and use those numbers.

/// Turns a kit id into a ThemeData. The only place a hex becomes a Color.
library;

import 'package:flutter/material.dart';
import 'package:merge_empire_fc/data/kit_palette.dart';
import 'package:merge_empire_fc/ui/theme/kit_theme_ext.dart';
import 'package:merge_empire_fc/ui/theme/stripe_painter.dart';
import 'package:merge_empire_fc/util/kit_theme.dart';

Color hexToColor(String hex) =>
    Color(0xFF000000 | int.parse(hex.substring(1), radix: 16));

ThemeData buildAppTheme({required String kitId, required bool light}) {
  final s = buildKitSurfaces(kitId: kitId, light: light);
  final kit = KitTheme(
    bg: hexToColor(s.bg),
    surface: hexToColor(s.surface),
    surface2: hexToColor(s.surface2),
    border: hexToColor(s.border),
    textMuted: hexToColor(s.textMuted),
    accent: hexToColor(s.accent),
    accentBright: hexToColor(s.accentBright),
    accentBrightInk: hexToColor(s.accentBrightInk),
    accentInk: hexToColor(s.accentInk),
    background: _backgroundFor(kitId, s, light),
  );
  return ThemeData(
    useMaterial3: true,
    brightness: light ? Brightness.light : Brightness.dark,
    scaffoldBackgroundColor: kit.bg,
    colorScheme: ColorScheme.fromSeed(
      seedColor: kit.accent,
      brightness: light ? Brightness.light : Brightness.dark,
    ),
    extensions: [kit],
  );
}

Decoration _backgroundFor(String kitId, KitSurfaces s, bool light) {
  // Only two of the six kits are stripes; the rest are smooth gradients.

  if (stripes != null) {
    final width = kitId == 'humbug' ? 28.0 : 24.0;

      light: hexToColor(stripes.$2),

      begin: Alignment.topCenter,

```dart
/// The live theme, derived from the save.
library;

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:merge_empire_fc/data/kit_palette.dart';
import 'package:merge_empire_fc/providers/game_providers.dart';
import 'package:merge_empire_fc/ui/theme/app_theme.dart';

final kitIdProvider = savePick<String>((s) {
  final club = s['club'];
  final id = club is Map<String, dynamic> ? club['kitPrimaryColor'] : null;
  return id is String ? id : defaultKitColor;
});

final lightModeProvider = savePick<bool>((s) {
  final settings = s['settings'];
  // Defaults TRUE, matching the schema: light reads better across the redesign.
  return settings is Map<String, dynamic> ? settings['lightMode'] != false : true;
});

/// Set by the Event route while a themed event is open.
///
/// A themed event is a fixed dark showpiece and forces dark for as long as it is
/// up. An event with NO palette — Deadline Day — must inherit the player's own
/// light mode: this is a property of the event, not of the screen, and forcing
/// dark on the way in once overrode light mode for an event that never asked.
final forcedDarkProvider = StateProvider<bool>((ref) => false);

final appThemeProvider = Provider<ThemeData>((ref) {
  final forcedDark = ref.watch(forcedDarkProvider);
  return buildAppTheme(
    kitId: ref.watch(kitIdProvider),
    light: forcedDark ? false : ref.watch(lightModeProvider),
  );
});
```

/// The stakes are why this is tested hard: the welcome-back entry holds coins
/// that exist nowhere else, so an entry that is dropped, expired or skipped is a
/// player's overnight earnings gone.
library;

import 'package:flutter_test/flutter_test.dart';
import 'package:merge_empire_fc/util/popup_queue.dart';

void main() {
  tearDown(resetPopupQueue);

  /// Records the order popups opened in, and hands back their `done` callbacks
  /// so a test can close them when it chooses.
  ({List<String> opened, Map<String, void Function()> close}) recorder() {
    return (opened: <String>[], close: <String, void Function()>{});
  }

  PopupEntry entry(
    String id,
    int priority,
    ({List<String> opened, Map<String, void Function()> close}) rec, {
    bool Function()? canShow,
  }) {
    return PopupEntry(
      id: id,
      priority: priority,
      canShow: canShow,
      show: (done) {
        rec.opened.add(id);
        rec.close[id] = done;
      },
    );
  }

  test('drains in priority order regardless of enqueue order', () async {
    final rec = recorder();

    enqueuePopup(entry('welcome', PopupPriority.welcomeBack, rec));

    expect(rec.opened, ['welcome']);
    rec.close['welcome']!();
    await Future<void>.delayed(Duration.zero);
    expect(rec.opened, ['welcome', 'daily']);
  });

  test('ties break by insertion order', () async {
    final rec = recorder();
    enqueuePopup(entry('first', 50, rec));
    enqueuePopup(entry('second', 50, rec));
    await Future<void>.delayed(Duration.zero);
    rec.close['first']!();
    await Future<void>.delayed(Duration.zero);
    expect(rec.opened, ['first', 'second']);
  });

  test('re-queueing a pending id is a no-op', () async {
    final rec = recorder();
    enqueuePopup(entry('a', 10, rec));
    enqueuePopup(entry('a', 10, rec));
    await Future<void>.delayed(Duration.zero);
    expect(rec.opened, ['a']);
    expect(isPopupPending('a'), isTrue);

    final rec = recorder();

    await Future<void>.delayed(Duration.zero);
    expect(rec.opened, ['a']);

    final rec = recorder();

      await Future<void>.delayed(Duration.zero);

    expect(hasPopupWork(), isTrue);
    unblockPopups('tutorial');
    await Future<void>.delayed(Duration.zero);
    expect(rec.opened, ['welcome']);

class PlaceholderScreen extends StatefulWidget {
  const PlaceholderScreen({super.key, required this.label});

  final String label;

  State<PlaceholderScreen> createState() => PlaceholderScreenState();

    with SingleTickerProviderStateMixin {
  late final AnimationController _controller = AnimationController(
    vsync: this,
    duration: const Duration(seconds: 2),

  /// Test seam: proves this screen kept its state across a tab switch.
  void bump() => bumps++;

  /// Test seam: whether TickerMode is letting this screen animate.
  bool get isTicking => _controller.isAnimating;

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) =>
      Center(child: Text(widget.label));
}

```dart
/// Which entrance an incoming screen gets.
///
/// Enter-only, as in the JS: the outgoing screen simply hides. The two slides
/// are the tab bar's left/right cue; fromBelow is for the Event, which is
/// reached from a strip pinned to the bottom of the Play screen, so rising from
/// under it is the movement the tap implies.
library;

import 'package:merge_empire_fc/ui/shell/tabs.dart';

enum EnterMode { none, fromLeft, fromRight, fromBelow }

/// Distance a horizontal drag must cover to change tab.
const double swipeThreshold = 60;

EnterMode enterModeFor({
  required ShellTab from,
  required ShellTab to,
  required bool noSlide,
}) {
  if (noSlide || from == to) return EnterMode.none;
  return tabOrder.indexOf(to) > tabOrder.indexOf(from)
      ? EnterMode.fromRight
      : EnterMode.fromLeft;
}
```

## Notes for whoever executes this

- **Task 4 Step 6 is a gate, not a formality.** If offscreen tabs keep ticking, `TickerMode` is not the replacement for `screenFreeze.js` that this design assumes, and the right response is to stop and say so rather than to work around it.
- **The six pattern kits are literal tables, not formulas.** Transcribe them from `applyKitColor` and let the fixture check your typing; no other test will notice a wrong hex.
- **Nothing in the popup queue may time out or discard.** If a change seems to need an expiry, it is the wrong change.
- **Placeholder tab bodies stay placeholders.** A real screen is its own module with its own spec; building one here would make this plan unreviewable.
