**Goal:** Land a synchronous `t()` over all ten translation catalogues, with the JS's exact fallback behaviour and its guard suite, before the first M3 screen exists.

**Architecture:** A node script converts the ten JS catalogues into generated Dart `const Map<String, String>` files. A small hand-written lookup layer holds the active catalogue in a module-scope singleton so `t()` stays synchronous and Flutter-free. A Riverpod provider sets that singleton and bumps a revision, mirroring how the save is already bridged to widgets.

**Tech Stack:** Dart 3.10.1 / Flutter 3.38.3, `flutter_localizations`, `flutter_riverpod`, node 26 for the generator.

**Spec:** `docs/superpowers/specs/2026-08-18-i18n-layer-design.md`

## Global Constraints

- Source of truth is `../merge-empire-fc/src/i18n/`. Read a JS file in full before porting it.
- `lib/engine/`, `lib/data/`, `lib/state/`, `lib/util/` must never import `package:flutter/*`. **`lib/i18n/` joins that list in Task 2.**
- `t()` is synchronous. No `Future`, no `async`, no `rootBundle`.
- Catalogue count is 2,652 keys × 10 locales — `en, es, pt, fr, de, it, ja, ko, zh, ar`. All ten are key-identical; any drift is a test failure, not something to paper over.
- Generated files end in `.g.dart`, carry a "GENERATED — do not edit" header naming the script, and are committed.
- Save key for the active locale is `state['settings']['locale']`.
- Comments: one short line each, never a block. This is a repo rule.
- Commit after every task.

Create `tool/gen_i18n.mjs`. The `import()`-the-JS-module approach is what every `tool/dump_*_reference.mjs` already does.

```js
// Converts the ten JS catalogs to generated Dart maps.
//
// Dart rather than ARB: 30 keys are not valid identifiers (a nation name with a
// space or a diacritic), and the engines look keys up at runtime from strings,
// which gen_l10n cannot do at all. See the i18n design spec.
//
//   node tool/gen_i18n.mjs

import { writeFileSync, mkdirSync } from 'node:fs';

const IDS = ['en', 'es', 'pt', 'fr', 'de', 'it', 'ja', 'ko', 'zh', 'ar'];
const SRC = '../merge-empire-fc/src/i18n/locales/';
const OUT = 'lib/i18n/locales/';

const HEADER = (id) => `// GENERATED by tool/gen_i18n.mjs — do not edit.
// Source: ../merge-empire-fc/src/i18n/locales/${id}.js
`;

// Dart single-quoted string literal. $ starts an interpolation in Dart and a
// backslash escapes, so both are escaped even though no value currently has one.
const lit = (s) =>
  "'" + String(s)
    .replace(/\\/g, '\\\\')
    .replace(/'/g, "\\'")
    .replace(/\$/g, '\\$')
    .replace(/\n/g, '\\n') + "'";

mkdirSync(OUT, { recursive: true });

const loaded = {};
for (const id of IDS) {
  loaded[id] = (await import(SRC + id + '.js')).default;
}

const enKeys = Object.keys(loaded.en);

for (const id of IDS) {
  const cat = loaded[id];
  const keys = Object.keys(cat);

  // A duplicate key would be a compile error in a const Dart map, but the error
  // would name a line rather than the catalog that produced it.
  const seen = new Set();
  for (const k of keys) {
    if (seen.has(k)) throw new Error(`${id}: duplicate key ${k}`);
    seen.add(k);
  }
  for (const k of keys) {
    if (typeof cat[k] !== 'string') throw new Error(`${id}: ${k} is not a string`);
  }
  if (id !== 'en') {
    const missing = enKeys.filter((k) => !(k in cat));
    const extra = keys.filter((k) => !(k in loaded.en));
    if (missing.length || extra.length) {
      throw new Error(`${id}: key drift — missing ${missing.length}, extra ${extra.length}`);
    }
  }

  const body = keys.map((k) => `  ${lit(k)}: ${lit(cat[k])},`).join('\n');
  writeFileSync(
    `${OUT}${id}.g.dart`,
    `${HEADER(id)}\n// ignore_for_file: lines_longer_than_80_chars\nlibrary;\n\n` +
      `const Map<String, String> ${id}Catalog = <String, String>{\n${body}\n};\n`,
  );
}

const imports = IDS.map((id) => `import 'package:merge_empire_fc/i18n/locales/${id}.g.dart';`).join('\n');
const entries = IDS.map((id) => `  '${id}': ${id}Catalog,`).join('\n');
writeFileSync(
  'lib/i18n/catalogs.g.dart',
  `// GENERATED by tool/gen_i18n.mjs — do not edit.\n\n${imports}\n\n` +
    `const Map<String, Map<String, String>> catalogs = <String, Map<String, String>>{\n${entries}\n};\n`,
);

process.stdout.write(`wrote ${IDS.length} catalogs, ${enKeys.length} keys each\n`);
```

// Reference output from the JS i18n runtime.
//
// The interesting behaviour is all in the failure cases: a key missing from the
// active catalog falls back to English, a key missing everywhere renders as
// itself, a param with no placeholder is ignored, and a placeholder with no
// param is left standing. None of them throw, and every one of them is a thing
// a screen will hit.
//
//   node tool/dump_i18n_reference.mjs > test/fixtures/i18n_reference.json

const i18n = await import('../../merge-empire-fc/src/i18n/index.js');

const out = { resolve: [], tName: [], locale: [] };

const resolve = (label, locale, key, params) => {
  i18n.setLocale(locale);
  out.resolve.push({ label, locale, key, params: params ?? null, value: i18n.t(key, params) });
};

resolve('plain', 'en', 'nav.squad');
resolve('plain translated', 'fr', 'nav.squad');
resolve('one param', 'en', 'gems.toast.season', { n: 5 });
resolve('two params', 'en', 'toast.cup_gems', { n: 3, cup: 'The Cup' });
// {s} exists in en and not in es — the extra param must be dropped silently.
resolve('param with no placeholder', 'es', 'event.news.after.missed', { n: 2, s: 's' });
resolve('placeholder with no param', 'en', 'gems.toast.season', {});
resolve('no params at all', 'en', 'gems.toast.season');
resolve('numeric param', 'en', 'gems.toast.tutorial', { n: 10 });
resolve('missing everywhere', 'en', 'no.such.key.anywhere');
resolve('missing everywhere, translated locale', 'ja', 'no.such.key.anywhere');
resolve('unknown locale falls back to en', 'xx', 'nav.squad');
resolve('rtl catalogue', 'ar', 'nav.shop');
resolve('key with a space', 'en', 'event.wc2026.fact.Bosnia and Herzegovina.0');
resolve('key with a diacritic', 'en', 'event.wc2026.fact.Türkiye.0');

i18n.setLocale('en');
out.tName.push({ label: 'by id', value: i18n.tName('nav', 'squad') });
out.tName.push({ label: 'by object', value: i18n.tName('nav', { id: 'squad', name: 'Fallback' }) });
out.tName.push({ label: 'unknown id falls back to name', value: i18n.tName('nav', { id: 'nope', name: 'Fallback' }) });
out.tName.push({ label: 'unknown id, no name, falls back to id', value: i18n.tName('nav', 'nope') });
out.tName.push({ label: 'unknown id, object with no name', value: i18n.tName('nav', { id: 'nope' }) });

  i18n.setLocale(id);

Create `lib/i18n/i18n.dart`:

```dart
/// The translation lookup, ported from `../merge-empire-fc/src/i18n/index.js`.
///
/// Deliberately Flutter-free and synchronous. `t()` is called from build methods
/// and from formatters next to the engines, so an async lookup would poison
/// every call site — which is why all ten catalogues are compiled in rather than
/// loaded on demand.
///
/// Reactivity lives in `providers/i18n_providers.dart`, not here.
library;

import 'package:merge_empire_fc/i18n/catalogs.g.dart';
import 'package:merge_empire_fc/i18n/detect.dart';
import 'package:merge_empire_fc/util/format.dart';

const Map<String, String> _en = <String, String>{};

String _locale = fallbackLocale;
Map<String, String> _catalog = catalogs[fallbackLocale] ?? _en;

/// Ten shipped catalogues.
List<String> get localeIds => catalogs.keys.toList();

/// An unknown or retired id lands on English: a corrupt save must not leave the
/// app without strings.
void setLocale(String? id) {
  final resolved = (id != null && catalogs.containsKey(id))
      ? id
      : fallbackLocale;
  _locale = resolved;
  _catalog = catalogs[resolved]!;
  setFormatLocale(resolved);
}

String getLocale() => _locale;

void resetLocale() => setLocale(fallbackLocale);

/// Active catalogue, then English, then the key itself — a missing translation
/// shows `ach.title.foo`, never blank UI.
String t(String key, [Map<String, Object?> params = const {}]) {
  final template = _catalog[key] ?? catalogs[fallbackLocale]![key] ?? key;
  if (params.isEmpty) return template;
  var out = template;
  // Literal replace, matching the JS split/join: a param with no placeholder is
  // ignored (57 catalogue entries drop English's {s}), and a placeholder with no
  // param is left standing. Neither is an error.
  params.forEach((k, v) => out = out.replaceAll('{$k}', '$v'));
  return out;
}

/// Resolve a division / cup / tier by its data-file id, falling back to the
/// object's English `name`.
String tName(String prefix, Object? idOrObj) {
  final String id;
  final String fallback;
  if (idOrObj is Map) {
    id = idOrObj['id'] as String? ?? '';
    fallback = idOrObj['name'] as String? ?? id;
  } else {
    id = idOrObj as String? ?? '';
    fallback = id;
  }
  final key = '$prefix.$id';
  return _catalog[key] ?? catalogs[fallbackLocale]![key] ?? fallback;
}
```

import 'package:flutter_test/flutter_test.dart';
import 'package:merge_empire_fc/data/manager_looks.dart';
import 'package:merge_empire_fc/data/manager_mood.dart';

/// Ported from `../merge-empire-fc/src/i18n/i18n.test.js`.
void main() {
  final en = catalogs['en']!;

  List<File> dartFiles() => Directory('lib')
      .listSync(recursive: true)
      .whereType<File>()
      .where((f) => f.path.endsWith('.dart') && !f.path.endsWith('.g.dart'))
      .toList();

  // Literal first arguments only. A key containing $ is interpolated, built at
  // runtime, and covered by the id-driven checks below instead. The lookbehind
  // is what stops `format(` and `expect(` matching the bare `t(`.
  final tCall = RegExp(r"(?<![\w.])t\(\s*'([^'$\\]+)'");
  final tNameCall = RegExp(r"(?<![\w.])tName\(\s*'([^'$\\]+)'");

  test('every literal t() key in lib/ exists in English', () {
    final used = <String, String>{};
    for (final file in dartFiles()) {
      for (final m in tCall.allMatches(file.readAsStringSync())) {
        used[m.group(1)!] = file.path;
      }
    }
    final missing = used.entries
        .where((e) => !en.containsKey(e.key))
        .map((e) => '${e.key}  (${e.value})')
        .toList();
    expect(missing, isEmpty, reason: 'These render as their own key:\n${missing.join('\n')}');
  });

  test('every tName() prefix resolves at least one English key', () {
    final prefixes = <String, String>{};
    for (final file in dartFiles()) {
      for (final m in tNameCall.allMatches(file.readAsStringSync())) {
        prefixes[m.group(1)!] = file.path;
      }
    }
    final unresolved = prefixes.entries
        .where((e) => !en.keys.any((k) => k.startsWith('${e.key}.')))
        .map((e) => '${e.key}  (${e.value})')
        .toList();
    expect(unresolved, isEmpty);
  });

  test('the scan actually looked at something', () {
    // Guards the two tests above from passing vacuously before any screen exists.
    expect(dartFiles(), isNotEmpty);
  });
}

```dart
/// The active locale, bridged to the widget tree.
///
/// `t()` stays a plain synchronous function over a module-scope singleton so the
/// engines and `dart test` can call it. This is the half that makes a change to
/// it rebuild the tree — the same split the save already uses.
library;

import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:merge_empire_fc/i18n/i18n.dart';
import 'package:merge_empire_fc/providers/game_providers.dart';

final localeProvider = NotifierProvider<LocaleNotifier, String>(
  LocaleNotifier.new,
);

class LocaleNotifier extends Notifier<String> {
  @override
  String build() {
    ref.watch(saveRevisionProvider);
    final save = ref.watch(gameProvider).state;
    final settings = save?['settings'];
    final stored = settings is Map<String, dynamic> ? settings['locale'] : null;
    // setLocale narrows an unshipped id to English, so read it back rather than
    // trusting what the save held.
    setLocale(stored is String ? stored : null);
    return getLocale();
  }

  /// The Settings picker. Writes the save, which is what makes it survive a
  /// restart; `build` above is what applies it.
  void set(String id) {
    ref.read(gameProvider).update((s) {
      final settings = s['settings'];
      if (settings is Map<String, dynamic>) settings['locale'] = id;
    });
    setLocale(id);
    state = getLocale();
  }
}
```
